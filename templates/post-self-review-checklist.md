# 블로그 글 자기검수 템플릿 (AI 티 줄이기)

> 사용법: 글 초안을 다 쓴 뒤, 아래 체크리스트를 위에서부터 체크하세요.
> 최종 기준은 "정보 전달"보다 "내가 실제로 겪은 맥락"이 보이는가입니다.

---

## 1) 빠른 경고 문장 패턴 체크

아래 패턴이 글 전체에서 많이 반복되면 AI 톤으로 읽히기 쉽습니다.

- [ ] `핵심은`, `정리하면`, `결론적으로` 같은 선언문이 2회 이하인가?
- [ ] `패러다임`, `본질`, `가능성`, `혁신` 같은 추상 명사가 과도하지 않은가?
- [ ] `Step 1/2/3`과 bullet만 이어지는 구간이 8줄 이상 연속되지 않는가?
- [ ] 모든 섹션 끝이 "핵심 요약" 형태로 동일하게 끝나지 않는가?
- [ ] "가장 좋다/대중적이다/가성비 최고" 같은 단정 표현에 근거가 있는가?

---

## 2) 사람 냄새 체크 (필수)

각 항목 중 최소 3개 이상 포함하세요.

- [ ] 내가 실제로 막혔던 지점 1개
- [ ] 처음에 잘못 이해했던 포인트 1개
- [ ] 바꿔서 시도한 방법 1개
- [ ] 그 결과가 어떻게 달라졌는지 1개
- [ ] 다음에 다시 할 때의 개선 계획 1개

문장 힌트:

- "처음엔 ~라고 생각했는데, 실제로 해보니 ~였다."
- "여기서 막힌 이유는 ~였고, ~로 바꾸니 풀렸다."
- "다음에는 ~부터 먼저 검증할 생각이다."

---

## 3) 섹션별 리라이트 가이드

### 도입부(첫 3문장)

- [ ] 일반론 대신 실제 장면으로 시작했는가?
- [ ] 숫자/시간/상황(예: 30분, 로그 12줄, 실패 2번) 중 1개 이상 포함했는가?
- [ ] 같은 키워드(AI, 에이전트, 핵심)를 반복하지 않았는가?

### 본문

- [ ] 정의 설명 뒤에 반드시 내 사례가 붙는가?
- [ ] 표/목록 다음에 "내 해석" 문단이 1개 이상 있는가?
- [ ] 독자가 따라 할 수 있는 최소 재현 경로가 있는가?

### 마무리

- [ ] 템플릿 결론("핵심 요약") 대신 이번 글만의 배운 점이 있는가?
- [ ] 다음 액션이 추상적이지 않고 측정 가능한가?
  - 나쁜 예: "더 공부해보겠다"
  - 좋은 예: "같은 프롬프트를 Suno/Udio에 넣어 3회 비교해보겠다"

---

## 4) 발행 전 최종 60초 점검

- [ ] 소리 내어 읽었을 때 발표문처럼 딱딱하지 않은가?
- [ ] "내가 왜 이렇게 판단했는지"가 드러나는가?
- [ ] 같은 문장 구조가 3번 이상 반복되지 않는가?
- [ ] 독자가 가져갈 한 가지 실전 팁이 명확한가?

발행 보류 기준(하나라도 해당하면 수정):

- [ ] 결론이 다른 글과 복붙처럼 읽힌다.
- [ ] 실습 글인데 실패/수정 로그가 없다.
- [ ] 모든 문장이 정답처럼 단정되어 있다.
